\chapter*{\Large \center Abstract}

% Guidance of how to write an abstract/summary provided by Nature: https://cbs.umn.edu/sites/cbs.umn.edu/files/public/downloads/Annotated_Nature_abstract.pdf

Automated email generation faces significant challenges achieving human-like quality and consistency across optimization strategies. Multi agent systems offer promising solutions for natural language generation, yet their effectiveness with Direct Preference Optimization remains unexplored, and existing evaluation methodologies lack standardized frameworks for comparing multiple model variants. This research implemented a three agent architecture comprising Email Generator, Checklist Creator, and Judge Agent to evaluate DPO effectiveness in automated fundraising email generation. The study systematically compared three model variants: Baseline, DPO Synthetic, and DPO Hybrid, using preference pairs derived from systematic evaluation across seven language models and fifty unseen validation topics. A comprehensive evaluation framework employed a novel Hybrid prompting strategy optimized for reasoning models, enabling complete three way comparison with balanced design and robust statistical analysis. Statistical analysis revealed equivalent performance across all optimization approaches, with no significant differences detected between Baseline, DPO Synthetic, and DPO Hybrid variants. Results demonstrate that sophisticated multi agent architectures maintain consistent email generation quality regardless of optimization complexity, challenging assumptions about complex DPO variants necessity with constrained datasets and suggesting architectural robustness exceeds optimization sophistication. The established Hybrid evaluation framework provides a transferable methodology for objective multi agent system assessment, contributing new standards for preference optimization evaluation in automated content generation.
